### 3.3 无障碍全零（P1）

### 3.4 一多适配缺失（P1）

- 全工程只有 **1 处** mediaquery：`ets/pages/Index.ets:77` 的
  `matchMediaSync('(dark-mode: true)')`，用途是深浅色，**不是窗口宽度断点**
- `entry/src/main/module.json5` 却声明了 `deviceTypes: ["phone", "tablet", "2in1"]` ——
  声明了不实现，比不声明更容易在审核被判不合格
- `harmony_check one_multi` 在 7 个文件命中 R007（缺断点）：ChatView、ConnectView、
  SessionsDrawer、SettingsView、MdDocViewer、SessionLocationSheet、MdLatex

### 3.5 hilog 直调违反 §7（P0，15 分钟可清）

`ets/entryability/EntryAbility.ets` 第 21/32/46/53/56/68/70 行共 **7 处** `hilog.*` 直调，
违反 AGENTS.md §7「hilog 一律封装在 `platform/Dlog.ets`」。

实际危害比字面违规更大：这里 DOMAIN 写的是 `0x0000`、TAG `DshChat`，而 `Dlog.ets` 用的是
`0xD5C0` / `Dsh`。**结果 Ability 生命周期日志（含崩溃前的 loadContent 失败）用
`hdc shell "hilog -x | grep A0D5C0"` 抓不到** —— 真机排障时就吃过这个亏。

### 3.6 动效时长不合档（P1）

`ets/pages/ChatView.ets:95` 会话抽屉 `.animation({ duration: 240, curve: Curve.EaseOut })`，
R017 要求落 100/200/300/400/500 档（240 → 200）。

全工程仅此一处 `.animation(` / `animateTo(`。

### 3.7 列表全量渲染（R005，17 个文件）

所有 `List` 都用 `ForEach` 而非 `LazyForEach`。当前 `HISTORY_MAX_MESSAGES = 200` 上限下没有
性能问题；历史分页放开后会显现。建议 v1.1 处理。

### 3.8 资源化缺口（口径问题，不是 bug）

- `$r('app.string.*')` 使用 **0 处**、`$r('app.color.*')` 使用 **0 处**
- 中文硬编码 `Text('…')` **92 处**
- `resources/{base,dark}/element/color.json` 各 6 色双套齐全，但**只被 `start_window_background` 引用**
- 未使用 string 资源 3 个：`skeleton_title`、`skeleton_badge`、`skeleton_body`（阶段 0 骨架遗留）
- 现状是与安卓严格同源（`DsPalette`/`DsTypography`/`DsSpacing` 常量类），改一处两端同步；
  代价是**不支持系统大字体缩放、不支持语言切换**
