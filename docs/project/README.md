# 项目文档索引 — dsh-Chat

本目录是**开发事实的落脚点**：状态、决策、坑位、测试与发布口径写在这里，
聊天记录可以帮忙讨论，但不能替代它。工程宪法在仓库根 [`AGENTS.md`](../../AGENTS.md)，
**文档与代码同提交**的纪律表在 §8（改 `lib/` 文件 → 同步 `docs/STRUCTURE.md`；
改设计 token → 同步 `docs/design-tokens.md` + `lib/design/tokens.dart`）。本目录不另立规矩。

## 现有文档

| 文档 | 回答什么问题 | 什么时候读 |
|---|---|---|
| [`../STRUCTURE.md`](../STRUCTURE.md) | 哪个文件干什么、新增文件该放哪；消费的 bridge 协议版本与帧；踩过的 6 条协议坑 | 改代码前、加文件前、对接协议出问题时 |
| [`../design-tokens.md`](../design-tokens.md) | 颜色/字号/间距/圆角各是多少、依据来自哪（官方 Web token + 真机 6 屏像素实测），App 与 Web 不一致时以谁为准 | 写任何 UI 之前；想引入一个「文档里没有的值」时 |
| [`../终版对比-官方vs本工程.png`](../终版对比-官方vs本工程.png) | 终版界面与原基准并排差在哪 | 评估视觉回归、判断某处是否「已经对齐」 |
